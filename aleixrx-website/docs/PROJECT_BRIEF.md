# Project Brief

## Objetivo
build a SPS (Single Page App) with Next.js + React using cleand code, good practices and patterns.

## Stack
- Next.js (App Router)
- React
- TypeScript

## Restrictions
- Don't do API calls (not REST, not GraphQL).
- Data will be:
  - mocks or
  - localStorage when it's need it.
- Avoid unnecessary dependencies. If something isn’t approved, it doesn’t get added.

## Alcance inicial (MVP sugerido)
- Home `/`
- Ejemplo de módulo "Tasks":
  - Listar tareas
  - Crear tarea
  - Marcar completada
  - Eliminar tarea
  - Persistencia en localStorage

## No alcance (por ahora)
- Autenticación real
- Backend
- SSR avanzado / SEO complejo
- Internacionalización
